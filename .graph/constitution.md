# Constitution

Las convenciones operativas viven en conventions.md; esto son solo las líneas rojas no-relajables.

- C1: El contrato `.graph/` entre `init` y `do` solo cambia de forma aditiva; `decisions.md`, `constitution.md` y `tasks/` jamás se regeneran ni se borran.
- C2: Tooling solo dentro de lo instalable: open source pinneado/vendoreado, o rehecho en casa con tests propios; cero prerrequisitos externos.
- C3: `docs/superpowers/` es registro histórico: specs y planes no se editan retroactivamente (su README índice es vivo y sí se actualiza).
- C4: Los commits de tareas GRAPH llevan el trailer `GRAPH-Task: <slug>`.
- C5: La información nunca se trunca ni se pierde: compresión solo estructural — mover íntegro a nodos enlazados.
